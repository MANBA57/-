## 条目名识别（多格式分册）

28 个分册行文格式不一，提取脚本按优先级识别钱币名：

1. 编号条目（`一、` / `1.` / `（一）` 等开头）——最常见；
2. 短粗体行（文档标题被消费后）；
3. 民国式**无标记短行**：非粗体、长度 ≤ 阈值、不以标点结尾、且后随长正文（> 50 字）；
4. 首个长文本（> 40 字）优先当朝代导语而非标题（三藩册）。

## 字段抽取规则

- **尺寸/重量**：沿用先秦管线的正则并放宽连接词（「直径只有1.2厘米左右」「重四铢（大约2.5克左右）」均可命中）；原文未给则留空，不造数。
- **时期**：`period` = 朝代中文名，`period_source` = `auto`（朝代由分册明确，非推断）；起止年取通行年表约数。
- **年份**：`year_mentioned` 兼顾「公元前 N 年 / 公元 N 年 / 裸公历年份」，公元前为负值。
- **材质**：青铜/红铜/黄铜/白铜/铁/铅/银/金/纸（宝钞、交子）等带语境匹配。
- **珍稀度**：扩展关键词表（存世量很少/极为罕见/孤品等）。
- **面文/背文/别名**：引号抽取；分册多为叙述体，覆盖率低于先秦原文，属数据实情。

字段覆盖率（385 币）：年份 257 / 材质 103 / 珍稀度 88 / 重量 32 / 直径 24 / 面文 4 / 别名 5。

## 导入（已执行，2026-10-11）

按**原图直出**策略导入（不压缩：重编码会损失钱文细节）：

```bash
cd services/api
# 先秦正册（第 1 册）
.venv/bin/python scripts/extract_docx.py --docx ../../docs/钱币简介-29册/1.先秦钱币简介.docx
# 28 个朝代分册（第 2–29 册）
.venv/bin/python scripts/extract_dynasties.py          # → 385 币 / 757 图引用
.venv/bin/python scripts/import_dynasties.py           # 两条管线原图直出 803 张（~253 MB，字节零改动）
.venv/bin/python scripts/build_db.py                   # 建库：29 时期 / 412 币 / 803 图 / 5 体系
.venv/bin/python scripts/validate.py --max-image-mb 300  # 门禁 ✓（2 条良性警告）
cd ../.. && pnpm build                                 # 418 条路由预渲染
```

- `import_dynasties.py`：从 docx 媒体库复制**原始字节**到 `static/images/{coins,categories}/<slug>/NN.png|jpg`，
  manifest 的 full/thumb 四个字段全部指向原图路径——前端 `<picture>` 无需改动；
- `build_db.py` 已扩展：`dynasties_import.json` 存在即自动并入（dynasty 表逐行插入、
  coin.dynasty_key 按记录写入、period_order 统一 +4 错开先秦时期序）；
- `validate.py` 已修正体积统计：按唯一路径累计（原图策略下同一文件被 4 个字段引用）；
- LQIP 仍是 16px 模糊占位（仅加载占位用，非展示图）。

## 已知边界

- 元末起义军、明代等分册有少量媒体图未被正文引用（zip 内存在但无 r:embed），未导出；
- 「方孔圆钱」是为无显式类别的朝代钱币新设的默认类别（秦半两按原文归既有「圜钱」）；先秦正册四体系（布/刀/圜/贝）自带类别与导语；
- 清代「雍正通宝」等少数条目原文即无配图或图注来源不明，库中如实缺图（validate 提示的 2 条良性警告）；
- 先秦正册原文自述 35 币、实际可结构化 27 币（其余为图片注记或重复条目），已在 report 中记录；
- 原图直出共 ~253 MB / 805 张，本地与内网部署无压力；若将来上公网且在意流量，
  可再评估「仅缩略图压缩、大图保持原图」的折中方案。
